Analysis of Discord Token Stealer

Overview and File Information

I found this file from a YouTube video where it was pretending to be a cracked program. After looking into it, I realized it was actually a password and token stealer that mainly targets Discord. When run, it collects sensitive info from the victim’s computer, sends it to a webhook server controlled by the attacker, and then tries to delete any traces of itself. This demonstrates the risk of downloading and running unknown executables from untrusted sources.

File Details

  • File Name: StealerBin.exe
  • File Size: 8.2 MB

1. Static Analysis

For static analysis, the file was inspected without execution using DnSpy to review the source code of the .NET executable.

Reviewing Code with DnSpy

Opening the executable in DnSpy revealed the underlying structure and exfiltration logic:

  • Hardcoded Discord webhook endpoints inside the source code:
  • Functions designed to locate browser data (such as Chrome and Firefox session data):
  • Routines for writing staged data to temporary directories such as C:\temp\[USER]_Passwords.txt:
  • Utilization of HttpClient routines to issue HTTP POST requests containing exfiltrated data.

VirusTotal Scan

Uploading the sample hash to multi-engine scanning services like VirusTotal and Hybrid Analysis confirmed detection coverage, with most vendors categorizing the sample under stealer or trojan classifications.

2. Dynamic Analysis

Dynamic analysis was conducted in an isolated sandbox environment to observe runtime behavior.

A. Runtime Behavior

Execution inside the sandbox confirmed the following actions:

  • Staged credentials locally under C:\temp\[USER]_Passwords.txt.
  • Scanned local application storage for Discord tokens.
  • Transmitted collected data out of the environment via the webhook endpoint.

B. Network Behavior

Monitoring network traffic via ANY.RUN demonstrated:

  • Outbound HTTP requests directed to Discord's API webhook infrastructure.
  • Transmission of staged tokens and credentials within the request payload.

C. Cleanup Behavior

The executable performed self-cleanup mechanisms post-exfiltration:

  • Removal of the staged local text file after completion of the upload.
  • Self-deletion routines executed to minimize local indicators of compromise.

D. Tools Used

  • DnSpy – Static analysis and decompilation of .NET binaries.
  • VirusTotal / Hybrid Analysis – Multi-engine antivirus signature scanning.
  • ANY.RUN – Interactive malware analysis sandbox for behavioral and network tracking.

3. Conclusion

Static and dynamic analysis confirm that the binary operates as an information stealer targeting Discord tokens and browser data.

Decompiled code analysis directly correlates with the observed sandbox execution: the program collects local credentials, exfiltrates them via outbound webhooks, and executes cleanup scripts upon completion.
